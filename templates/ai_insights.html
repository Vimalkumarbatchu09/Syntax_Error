Explainable AI (XAI) Telemetry Engine Architecture

NetGuard AI pairs a trained Random Forest Classifier (100 estimators) for high-accuracy binary classification (Normal vs Anomaly) with an XAI Telemetry Explanation Layer. Rather than treating machine learning as an uninterpretable black box, the system computes deviation ratios across 8 network features (bandwidth, latency, packet loss, CPU, RAM, active sockets, packets sent/received) relative to baseline operational profiles. This derivation enables transparent, deterministic explanations answering what occurred, which features contributed, how severe the event is, and what actions the NOC operator should enact.
